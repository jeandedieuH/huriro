# @huriro/i18n

Every user-facing string goes through this catalog (§17.8) — `t(id)` or `<Trans>`,
never inline literals in `apps/*`. The `en` catalog is the source of truth;
`pseudo` is generated by `bun run gen` (accent + wrap + pad to catch truncation).

- Add a string → `locales/en.ts`, run `gen`, commit both.
- `MessageId` is typed off `en` — a missing id fails typecheck.
- Lingui macro/extract tooling lands with the CI string-lint gate; for M0 the
  catalog is hand-maintained.
